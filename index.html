Excel input template

This is an exact, unmodified copy of the Development Bank of Ethiopia “Bond Sales, Employees Contribution and Donation Report” workbook (single sheet, Sheet1) — same headers, layout, dropdowns and formulas as the official file. The left block (columns B–D) records DBE-Head Office / CBE / Micro Finance Institutions figures for the period set in cells C4:C9; the right block (columns F–L) records the per-district breakdown for the period set in cells H4:H9. Download it, fill in the designated cells only, and re-upload the same file below — the app recognizes it automatically by its structure.

Import from file

Import the filled-in Excel input template above (its exact structure is auto-detected — recommended for FY2026/27 onward), or a simple .csv / .xlsx with columns Fiscal Year, Quarter, Month, Group, Sales Unit, Operating Unit, Restructuring, Plan, Actual (header names are matched loosely — e.g. "FY", "Unit", "Structure" also work). The downloadable template and the file this importer accepts are the same file — download it, fill it in, and upload the completed copy here.
